此程序根据 stuinfo.csv 中的信息登陆浙江大学 zdbk 爬取**本科生**成绩信息并自动计算均绩

**请保证网速足够，并关闭代理。如果打开 zdbk 很卡，程序大概率会失败** 

## 源代码文件

- 用到的库包括 selenium (3.141.0) 与 pandas (2.0.3)

- auto.py 是函数定义文件

- main.py 是主程序文件

- label.png 是程序图标

## 启动程序

1. 请将 stuinfo_xx.csv 改名为 stuinfo.csv ，并将文件中 stuid, 后的xxxxxxxxxx改为学号，将 password, 后的xxxxxxxx改为登录密码
2. 点击 ZJUGPA.exe 并耐心等待，因校网和爬虫不是非常稳定，程序可能会报错退出，重复启动几次直到成功显示均绩即可
3. 成功后会自动生成 gpa_auto.csv ，其中是爬取的成绩信息，最后的均绩仅供参考，原因比如有

   - **请注意由于各专业的培养方案不同，部分国际化课程、通识课程等可能无法识别是否主修，因此主修绩点可能并不准确**
- 类似英语水平测试这种课程采用 P/F 制，通过之后绩点记为 3 ，对于这种绩点本程序也将计入均绩的计算，但是有的学院可能不会将此计入均绩计算
